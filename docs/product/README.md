# SupportPilot 产品文档

本目录记录 SupportPilot 的业务范围与阶段验收口径。它是后续数据库、RAG、Agent、前端和评测实现的产品基线；需求变化应先修改这里，再修改代码。

## 当前产品基线

- 演示业务域：虚构的 B2B API/开发者平台 `ExampleAPI`。
- 产品定位：面向企业 SaaS 的技术支持与智能工单 Agent，不是通用聊天机器人。
- 核心闭环：问题进入、意图与风险识别、知识或业务数据查询、证据化解决方案、置信度门控、自动回复或工单升级、人工处理、反馈回流。
- 数据原则：仅使用明确标注的合成数据、人工标注数据和许可兼容的公开资料，不冒充真实生产数据。

## 变更规则

以下变化会明显影响产品方向，执行前需要用户确认，并同步更新本文档：

- 更换演示 SaaS 业务域或首要用户；
- 接入真实企业数据、私有历史工单或新的外部付费数据源；
- 允许系统执行退款、权限修改、密钥轮换或运维命令等高风险动作；
- 扩大 MVP 到多渠道接入、多语言、语音、生产部署或多组织复杂计费；
- 调整核心成功标准或降低安全门槛。
